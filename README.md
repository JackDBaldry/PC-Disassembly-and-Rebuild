# PC Disassembly and Rebuild
Edexcel iGCSE PC Disassembly and Rebuild Project

This project followed the Cisco Networking Academy [Computer Hardware Basics](https://www.netacad.com/courses/computer-hardware-basics?courseLang=en-US) course units: 

1.3. Computer Disassembly

1.4. Open the Case and Connect the Power Supply

1.5. Install Motherboard Components

1.6. Install Drives and Adapter Cards

1.7. Install Cables and Complete Assembly

I disassembled and reassembled a desktop PC following the course instructions, noting the specific hardware components as I went and then investigated them individually.

## Step by Step of Disassembly

Video 1.3.3 and 1.3.4 Lab manual which are both in the course and they show how to fully disassemble the computer and is what I used to help me know what order to take each part out of the computer.

Here is the rough step by step process of how we took apart the computer: 

1. We made sure the computer was fully unplugged and powered off

2. We had to unscrew all the screws that were holding the side panel on so we could access all the internal parts of the computer

3. We removed all the main major components which are the HDD, optical drive, power supply, heat sink, graphics card and RAM. This involved unplugging all data and power cables, looking if the parts were screwed in or had sliding mechanisms and then removing them depending on how they were mounted in the computer.

We had to make sure to handle all the parts carefully so nothing got scratched or damaged in the process of taking it apart. We had to adapt the disassembly order that was shown in the course as our machine was different to the one they showed, so we had to adapt this section to make it work for us.

## Challenges and Reflections

I had never had done a full PC disassembly before so I had to learn about managing things like electrostatic charge, care of delicate items like the platter, remembering the sequence items were removed for later reassembly, etc. 
  
Some components were much more difficult to put back in the correct order so I had to refer to the pictures I had taken to ensure I had done it correctly. It was very satisfying when the fully reassembled machine ran well after I was done.
  
It was the first time I'd fully taken apart and reassembled a computer and I found it a very enjoyable experience and I enjoyed figuring out how all the components disassembled and reassembled. It also taught me a lot about how the computers parts worked together.
